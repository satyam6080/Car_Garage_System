# Car Garage Management System

## Overview

The **Car Garage Management System** is a simple Java console application that allows a garage to manage customer details, select car services, and generate a bill based on the selected services.

This project demonstrates the use of object-oriented programming (OOP) concepts in Java, including classes, objects, arrays, exception handling, and user input.

---

## Features

* Add customer details

  * Customer Name
  * Car Number
  * Car Type
* Display available garage services
* Select one or more services
* Calculate the total service cost
* Generate a detailed bill
* Basic exception handling for invalid service selection

---

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Scanner Class
* Exception Handling

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/CarGarageManagement.git
```

2. Open the project in your preferred Java IDE (VS Code, IntelliJ IDEA, or Eclipse).

3. Compile the Java files.

```bash
javac *.java
```

4. Run the application.

```bash
java App
```
